# Portfolio site for Gabi Herbert

## About
Personal portfolio for an industrial engineer working in mining exploration and analysis.

## Tech
- Plain HTML and CSS only, no frameworks or build tools
- Keep everything in index.html and styles.css unless asked otherwise
- Mobile friendly
- Exception: globe.gl may be loaded from a CDN for the Journey globe
- Globe location data lives in data.js, separate from the globe code

## Writing style
- Concise, direct, professional
- No em dashes

## Confidentiality (strict)
- Never include company names, project or permit names, people's names,
  or figures related to my mining work
- Location: country level only (Côte d'Ivoire). Pin the country's centre,
  never a town, region or coordinates near the project
- Describe mining work only in general terms (e.g. "an early-stage gold exploration company")

## Git
- Never commit or push unless I ask

## Design
- Palette: greens, greys, blacks and whites only. Classy and restrained.
- All colours are CSS variables in :root in styles.css. Never hard-code a colour.
- Green is an accent, not a background for large areas (except dark sections)
